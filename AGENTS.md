# AGENTS.md — Full Stack FastAPI Template

## Stack

- **Backend**: Python 3.10+, FastAPI, SQLModel (SQLAlchemy + Pydantic), PostgreSQL, Alembic
- **Frontend**: React 19, TypeScript, Vite 7, TanStack Router, TanStack Query, shadcn/ui, Tailwind v4
- **Infra**: Docker Compose, Traefik, Mailcatcher (local dev)
- **Toolchain**: `uv` (Python), `bun` (JS), `prek` (pre-commit runner), `biome` (JS lint/format), `ruff` (Python lint/format), `mypy` (Python types), `ty` (Python type check)

## Key commands

```sh
# Full stack dev
docker compose watch                       # Start all services with live reload

# Backend only (outside Docker)
cd backend && fastapi dev app/main.py      # Dev server with hot reload

# Frontend only (outside Docker)
bun run dev                                # Vite dev server at :5173

# Backend tests (inside Docker: docker compose exec backend bash ...)
bash scripts/tests-start.sh                # Run all tests with coverage
bash scripts/tests-start.sh -x             # Stop on first failure
bash scripts/test.sh                       # Inside container only (pytest + coverage)

# Backend tests (full CI simulation)
bash scripts/test.sh                       # Builds + runs + tears down

# Frontend E2E tests
docker compose up -d --wait backend        # Ensure backend is running
bunx playwright test                       # Run Playwright tests
bunx playwright test --ui                  # Interactive UI mode

# Lint/format
bun run lint                               # Biome (frontend)
uv run ruff check backend/app              # Ruff (backend)
uv run ruff format backend/app --check     # Ruff format check
uv run mypy backend/app                    # mypy (backend)
uv run ty check backend/app                # ty (backend)
uv run prek run --all-files                # Run all pre-commit hooks
bash backend/scripts/lint.sh               # All backend checks (mypy + ty + ruff)

# DB migrations (inside container: docker compose exec backend bash)
alembic revision --autogenerate -m "msg"   # Create migration
alembic upgrade head                       # Apply migrations

# Generate frontend OpenAPI client
bash scripts/generate-client.sh            # Dumps OpenAPI JSON → generates TS client → lints

# Setup pre-commit hooks
uv run prek install -f                     # Install prek as git hook
```

## Architecture

- **Backend entrypoint**: `backend/app/main.py` — FastAPI app, includes router at `/api/v1`
- **API routes**: 
  - `backend/app/membership_service/routes/` — login.py, users.py, private.py (local only, conditionally included)
  - `backend/app/todo_service/routes/` — items.py
  - `backend/app/api/routes/utils.py` — utility endpoints (health check, test email)
- **Models**:
  - `backend/app/membership_service/models.py` — User, Token, Message, and auth-related schemas
  - `backend/app/todo_service/models.py` — Item model and schemas
  - `backend/app/models.py` — Re-export hub for Alembic migration discovery (imports all service models)
- **Config**: `backend/app/core/config.py` — Pydantic `Settings` reads `../.env` (one level above backend/)
- **DB**: `backend/app/core/db.py` — engine + init_db. Connection string built from env vars
- **Tests**: `backend/tests/` — Pytest, session-scoped DB with cleanup. Coverage threshold: 90%
- **Frontend entrypoint**: `frontend/src/main.tsx` — TanStack Router + Query setup
- **Frontend routes**: `frontend/src/routes/` — File-based routing via TanStack Router plugin. Auto-generated `routeTree.gen.ts`
- **Generated client**: `frontend/src/client/` — OpenAPI TS client generated by `@hey-api/openapi-ts`. Regenerate with `scripts/generate-client.sh`
- **shadcn/ui components**: `frontend/src/components/ui/`

## Repo-specific conventions

- Python deps managed via `uv sync` (in `backend/`). JS deps via `bun install` (root workspace delegates to `frontend/`)
- Pre-commit runner is `prek` (not `pre-commit`), config in `.pre-commit-config.yaml`. Runs ruff, biome, mypy, ty, generates client, checks zizmor
- `prek` auto-formats and commits changes in CI (when `PRE_COMMIT` secret exists) — beware of auto-commits
- Backend tests require Postgres and Mailcatcher running. CI starts them via `docker compose up -d db mailcatcher` before tests
- Playwright tests run inside Docker via `compose.yml`'s `playwright` service, sharded across 4 runners in CI
- PRs must have one label from: `breaking,security,feature,bug,refactor,upgrade,docs,lang-all,internal`
- Secrets check: `SECRET_KEY`, `POSTGRES_PASSWORD`, `FIRST_SUPERUSER_PASSWORD` must not be `changethis` in non-local envs
- Email templates use MJML source in `backend/app/email-templates/src/`, build to `backend/app/email-templates/build/`
